# AI Research & Report Generation System

## Features
- Multi-source research coordination
- Structured content assembly pipeline
- Self-validating quality checks
- Ephemeral data storage
- CrewAI agent integration

## Quick Start
```bash
pip install -r requirements.txt
python main.py --query "Your research topic"
```
